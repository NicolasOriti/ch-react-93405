
# Recomendaciones

## Tipos de componentes 

* Estructurales : Componentes que representan partes muy grandes de la app (App,Header,Main,Footer)
* Reutilizables : Componentes que me sirven todo el tiempo (Button,Card,Section, Input)

* Containter(contenedores) : Son componentes complejos, tienen logica y no sirven para mostrar JSX. Teadicionalmente van a retornar un componente Presentacional
* Presentational : Son componentes simples, no tienen mucha logica adentro y sirven principalmente para mostrar JSX
